I build systems where **hardware and software meet** — embedded firmware, custom electronics, control and mechanical design — and I'm exploring how **AI can turn software into useful products**.

### 🔭 Right now

- 🚀 **[ARIS](https://aris-space.ch)** — electronics & embedded Rust firmware for student rocketry at ETH Zürich ([asteria-firmware](https://github.com/aris-space/asteria-firmware))
- 🛒 **EasyCart / LazyCart** — co-founder; building an AI shopping assistant that helps shoppers explore a merchant's catalogue, compare products and assemble a basket
- 🤖 **Robotics** — embedded control and mechanical development for a line-following delivery robot
